# Marketing Campaign Analytics

## Project Overview

This project explores digital marketing campaign performance through data analysis, using SQL, Python and business KPIs to evaluate marketing effectiveness, customer acquisition and financial returns.

The project uses a simulated e-commerce marketing dataset to investigate how different advertising channels contribute to business growth.

## Business Objectives

- Evaluate marketing campaign performance.
- Identify the most cost-effective advertising channels.
- Analyze customer acquisition and conversion rates.
- Compare advertising expenditure and generated revenue.
- Develop data-driven marketing recommendations.
- Explore opportunities for budget optimization.

## Marketing Channels

- Google Ads
- Instagram Ads
- Facebook Ads
- Email Marketing
- TikTok Ads

## Key Performance Indicators (KPIs)

- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Conversion Rate (CVR)
- Cost Per Acquisition (CPA)
- Return on Ad Spend (ROAS)
- Return on Investment (ROI), where sufficient cost data is available

## Tools & Technologies

- SQL

## Methodology

1. Dataset creation and preparation
2. Data cleaning and validation
3. Exploratory data analysis
4. SQL queries and KPI calculations
5. Data visualization
6. Business insights and recommendations

## Data Source

This project uses synthetic marketing data created for educational and analytical purposes. It does not represent an actual company's financial or customer information.
